THE INPUT LAYER

Less prompt ceremony.
More useful first turns.

You do not need to write like a specification author to get a specification-quality starting point. The extension handles the translation while leaving the work to Pi.

01 / CONTEXT

Only the files that matter.

The active model sees a bounded project inventory, chooses relevant paths, and gets only validated context. No fixed filename list. No context dump.

⌁ project/
↳ src/auth.ts selected
↳ node_modules/ ignored
↳ tests/auth.test.ts selected

02 / CONTINUITY

Same model. No detour.

Rephrasing uses the model already selected for your Pi session. One mental model from first keystroke to finished change.

openai / gpt-5 active

03 / RECOVERY

Failure stays quiet.

Timeout, malformed selection, or missing auth? Pi gets your original input. The extension never traps the request.

↳ original input preserved
