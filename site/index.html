How it works

Three steps, one fallback.

The extension sits in front of Pi's normal input pipeline. On every interactive, non-steering prompt, it runs a short loop and hands the rephrased text back. If anything in the loop fails, Pi receives the original input unchanged.

  1. 01

    Capture

    Keep original user and assistant messages plus recent tool results in a bounded session buffer. Project files are never scanned.

    ⌘
  2. 02

    Bound

    Choose a short recent-history window from the session buffer. No extra classifier call can delay the rephrase.

    ◎
  3. 03

    Rephrase

    Hand only required conversation context to the same model and return one sharper prompt to Pi's normal input pipeline. Pi does the rest.

    ↗

The contract

Quiet by design.

Every state below is observable from Pi's own notifications. The extension never traps a prompt.

disabled
Set PI_REPHRASE_OFF=1 and Pi receives your input unchanged. There is no other way to mis-route the prompt.
extension-sourced input
Other extensions' output is passed through. Only interactive prompts are rephrased.
steer streaming
Mid-stream steering is passed through. Rephrasing only runs on completed, interactive prompts.
conversation context
Recent history stays bounded and uses original user wording. The cwd is never scanned, read, or sent to the model; use explicit @file references when needed.
rephrase fails
Timeout, missing authentication, or empty model output — Pi receives the original input. Set PI_REPHRASE_DEBUG=1 to see the rephrased text in stderr.

Configuration

Optional. Sensible defaults.

Five environment variables, all optional. The defaults below come straight from the source.

Name Default Effect
NamePI_REPHRASE_TIMEOUT_MS Default8000 EffectMaximum time for each rephrase attempt.
NamePI_REPHRASE_MAX_RETRIES Default2 EffectRetries transient rephrase failures.
NamePI_REPHRASE_RETRY_BASE_MS Default500 EffectBase delay for exponential retry backoff.
NamePI_REPHRASE_OFF Default0 EffectSet to 1 to bypass rephrasing entirely.
NamePI_REPHRASE_DEBUG Default0 EffectSet to 1 to write the rephrased text to stderr.

Install

One command. Private repo.

The package is hosted on GitHub and requires SSH authentication. After install, Pi loads the extension on every session until you remove it.

$ pi install git:git@github.com:AungMyoKyaw/pi-rephrase-input

Local checkout · pi install /path/to/pi-rephrase-input
