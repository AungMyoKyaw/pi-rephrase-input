How it works

Three steps, one fallback.

The extension sits in front of Pi's normal input pipeline. For eligible interactive prompts, it runs a short loop and hands the rephrased text back. Gated, interrupted, or failed requests pass through unchanged.

  1. 01

    Capture

    Capture original user and assistant messages plus recent tool results in bounded session buffers. Project files are never scanned.

    ⌘
  2. 02

    Bound

    Use the last two conversation messages for short histories, or the full six-message buffer for longer ones. Keep up to three tool-result snapshots and no extra classifier call.

    ◎
  3. 03

    Rephrase

    Ask the same selected model for one sharper prompt. Preserve pasted payload and attached images, then return both text and images to Pi.

    ↗

The contract

Quiet by design.

Pass-through is the default outside a successful transform. The extension never traps a prompt.

disabled
Set PI_REPHRASE_OFF=1 and Pi receives your input unchanged. There is no other way to mis-route the prompt.
input gates
Extension and RPC messages, steer and follow-up inputs, empty text, text containing @, slash commands, and sessions without a model or auth skip the rephrase model call. Eligible interactive input can still normalize supported clipboard images into attachments.
conversation context
Original wording stays in a rolling buffer of six messages. Tool results keep three snapshots. Conversation and tool text are capped at 2,000 and 1,000 characters; the cwd is never scanned or sent.
pasted payload
Pasted text is marked as user payload and preserved exactly by the rephrase prompt. Attached images go to the rephrase model and return with transformed input. Pi TUI clipboard paths are decoded from its temporary directory and removed from the text.
interrupt or failure
TUI Escape and Ctrl-C abort active requests. Timeout, provider error, empty output, or retry exhaustion sends original text and attachments through. PI_REPHRASE_DEBUG=1 logs diagnostics to stderr.

Configuration

Optional. Sensible defaults.

Five environment variables, all optional. The defaults below come straight from the source.

Name Default Effect
NamePI_REPHRASE_TIMEOUT_MS Default8000 EffectWall-clock cap for each rephrase attempt; retries can add more total time.
NamePI_REPHRASE_MAX_RETRIES Default2 EffectAdditional attempts after transient thrown errors; 0 disables retries.
NamePI_REPHRASE_RETRY_BASE_MS Default500 EffectBase cap for jittered exponential retry backoff.
NamePI_REPHRASE_OFF Defaultunset EffectSet to 1 to bypass rephrasing entirely.
NamePI_REPHRASE_DEBUG Defaultunset EffectSet to 1 to log rephrased output and retry/skip/interrupt diagnostics to stderr.

Install

One command. SSH access.

The private package is hosted on GitHub and uses SSH authentication. Pin master when installing; Pi loads the extension on every session until you remove it.

$ pi install git:git@github.com:AungMyoKyaw/pi-rephrase-input@master

Local checkout · pi install /path/to/pi-rephrase-input
